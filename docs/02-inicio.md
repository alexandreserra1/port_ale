# 02 — Página Inicial (index.astro)

## Objetivo

Apresentação profissional de impacto, com navegação clara para as demais seções.

## Conteúdo

1. **Hero / Apresentação**
   - Nome
   - Título/função atual (ex.: Engenheiro de Software | Backend & Data)
   - Frase de efeito curta
   - Foto de perfil (opcional)

2. **Tecnologias Principais**
   - Ícones ou badges das principais stacks (Python, Go, Rust, bancos, etc.)
   - Layout visual e escaneável

3. **Projetos em Destaque**
   - 3 a 4 projetos mais relevantes
   - Card com: nome, descrição curta, techs, link

4. **CTA (Call to Action)**
   - Links rápidos: GitHub, LinkedIn, Currículo
   - Botão "Ver projetos" ou "Contato"

## Layout

- Visual escuro e minimalista
- Seções em cascata vertical
- Navegação fixa no topo (Header)
