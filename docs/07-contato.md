# 07 — Página Contato (contato.astro)

## Objetivo

Oferecer meios de contato direto e redes sociais.

## Conteúdo

- LinkedIn (link)
- GitHub (link)
- E-mail (link mailto: ou formulário)

## Observações

- GitHub Pages não suporta backend para formulário
- Opções para formulário: serviço externo (ex.: Formspree, Web3Forms) ou link mailto:
- Design minimalista: ícones sociais com hover
